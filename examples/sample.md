# Markdown to DOCX 示例

这是一段普通文本，包含 **粗体**、*斜体*、`inline code` 和链接：
[Pandoc](https://pandoc.org/)。

## 列表

- 支持无序列表
- 支持 **强调**
- 支持任务列表

- [x] 已完成事项
- [ ] 未完成事项

## 表格

| 项目 | 说明 |
| --- | --- |
| 标题 | Markdown heading 会转成 Word 标题 |
| 表格 | GFM table 会转成 Word 表格 |
| 公式 | LaTeX math 会转成 Word 公式 |

## 公式

行内公式：$E = mc^2$。

块级公式：

$$
\int_0^1 x^2 dx = \frac{1}{3}
$$

## 引用

> Markdown 结构会被转换成 DOCX 中对应的段落、标题、列表和表格结构。
